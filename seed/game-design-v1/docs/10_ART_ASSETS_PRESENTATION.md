# Art, Assets, and Presentation

## Look

Warm stylized isometric 3D.

Reference:
- model railway
- architectural miniature
- digital board game
- handcrafted diorama

## Environment assets

- grass
- road
- forest
- river
- bridge
- hill
- open field
- protected area
- construction site

## Buildings

- house A/B
- café
- workshop
- light-industry hall
- station
- depot

Each building should have:
- day state
- emissive/night state
- electrical connection point
- optional simple animation

## Electrical assets

MVP:
- LV pole
- MV pole
- LV/MV lines
- transformer
- small substation
- external grid pylon
- solar array
- battery container

Later:
- wind turbine
- larger substation
- HV pylon
- hydro plant
- dispatchable generator

## Visual feedback

Successful supply should be visible:
- windows light up
- café sign activates
- workshop machinery moves
- station lights activate
- train/depot activity starts
- battery SOC changes
- solar panels react to sunlight
- power paths highlight in inspection mode
