# Power Places — Entire Game Design

## One-line pitch

**Build the grid. Grow the place. Understand why it works.**

Power Places is a relaxing isometric strategy/puzzle game about designing the electrical infrastructure behind a growing community.

The player starts with a few homes and a small business, then gradually has to support a village, workshops, transport, industry, and eventually multiple communities. The challenge is not simply producing enough electricity. The player must understand:

- where electricity comes from,
- when it is available,
- where it is needed,
- whether the network can deliver it,
- and how geography changes the best solution.

The game is designed to teach how electrical grids work through play rather than through textbook-style instruction.

## Core fantasy

The player watches a small place come alive because they built the invisible infrastructure behind it.

Windows light up.
Workshops start.
Trains arrive.
Batteries discharge.
Solar output falls with sunset.
Transformers approach capacity.

The player gradually understands that a power grid is not one big "energy number", but a changing system of generation, transport, storage, demand, and timing.

## Tone

- calm
- tactile
- optimistic
- educational without feeling like school
- visually charming
- understandable failures instead of punishment
- experimentation encouraged

## Visual identity

A warm, handcrafted isometric miniature world: somewhere between a model railway, a board game, and an architectural diorama.
